# منصة هور | HOR E-commerce Platform
منصة تجارة إلكترونية متعددة المتاجر تم تطويرها خصيصاً لتسهيل البيع والشراء أونلاين.

## مميزات المنصة:
- إمكانية إنشاء متجر خاص بكل تاجر بسهولة.
- عرض المنتجات وتصفحها حسب التصنيفات.
- سلة تسوق ذكية وإتمام الطلبات مع خيارات دفع متعددة.
- لوحة تحكم خاصة بالمبرمج والمتاجر.
